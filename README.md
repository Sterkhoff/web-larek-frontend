Структура проекта:
- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами
- src/components/base/ — папка с базовым кодом

Важные файлы:
- src/pages/index.html — HTML-файл главной страницы
- src/types/index.ts — файл с типами
- src/index.ts — точка входа приложения
- src/scss/styles.scss — корневой файл стилей
- src/utils/constants.ts — файл с константами
- src/utils/utils.ts — файл с утилитами

## Установка и запуск
Для установки и запуска проекта необходимо выполнить команды

```
npm install
npm run start
```

или

```
yarn
yarn start
```
## Сборка

```
npm run build
```

или

```
yarn build
```

# Описание базовых классов, их предназначение и функции.

Api - класс, описывающий работу с сервером
Функции:
get - Отправляет GET запрос по переданному URI и обрабатывает ответ сервера
get - Отправляет POST, PUT или DELETE запрос по переданному URI, в теле запроса передает переданный в нее объект
и обрабатывает ответ сервера

EventEmitter - класс, отвечающий за обработку событий
Функции:
on - Установить обработчик на событие;
emit - Инициировать событие с данными

# Описание паттерна MVC.
Model — отвечает за данные и бизнес-логику.
View — отображение данных, полученных от модели.
Controller — обрабатывает действия пользователя, отображает их во View.

# Model
BasketModel - отвечает за товары в корзине, обрабатывает их удаление и добавление.
OrderModel - класс, отвечающй за выбор способа оплаты, адреса доставки, контактов заказчика.
ProductGalleryModel - класс, отвечающий за содержимое каталога

# View
BasketItemView - отображение товара в корзине
BasketView - отображение корзины
ContactsView - отображение контактных данных заказчика
ModalView - базовый класс модального окна
OrderSuccessView - отображение успешно завершенного заказа
OrderView - отображеие информации о заказе.
ProductCardFullView - отобрражение подробной информации о товаре.
ProductCardGalleryView = отображение каталога товаров
ProductView - отображение товара в каталоге

# Controller
BasketController - логика добавления и удаления продуктов в корзину.
OrderController - логика добавления деталей заказа.
