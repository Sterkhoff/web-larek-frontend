# Описание базовых классов, их предназначение и функции.

Api - класс, описывающий работу с сервером
Функции:
get - Отправляет GET запрос по переданному URI и обрабатывает ответ сервера
get - Отправляет POST, PUT или DELETE запрос по переданному URI, в теле запроса передает переданный в нее объект
и обрабатывает ответ сервера

EventEmitter - класс, отвечающий за обработку событий
Функции:
on - Установить обработчик на событие;
off - Снять обработчик с события;
onAll - Слушать все события;
offAll - Сбросить все обработчики
emit - Инициировать событие с данными
trigger - Создает коллбек триггер, генерирующий событие при вызове.

# Описание паттерна MVC.
Model — отвечает за данные и бизнес-логику.
View — отображение данных, полученных от модели.
Controller — обрабатывает действия пользователя, отображает их во View.

# Model
CartModel - отвечает за товары в корзине, обрабатывает их удаление и добавление.
OrderModel - класс, отвечающй за выбор способа оплаты, адреса доставки.
UserContactsModel - класс, отвечающий за ввод персональных данных покупателя.

# View
ModalView - базовый класс для модальных окон
CatalogView - отображение каталога товаров на главной странице
ProductInfoView - отображеие модального с описанием товара
BasketView - отображеие модального с информацией о товарах в корзине
OrderView - отображеие модального с информацией о способе оплаты и адресом доставки
UserContactsView - отображеие модального с контактами пользователя.
BuyView - отображеие модального окна успешного оформления заказа.

# Controller
CartController - класс, отвечающий за логику добавления и удаления продуктов в корзину.
OrderController - класс, отвечающий за логику добавления деталей заказа.
BuyController - класс, отвечающий за отправление заказа.
